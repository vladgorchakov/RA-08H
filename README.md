# ESP32 MicroPython LoRaWAN Node (AI-Thinker RA-08H)

Автономная сенсорная нода на базе **ESP32** и **MicroPython** для мониторинга климатических параметров (температура, влажность) и передачи телеметрии по протоколу **LoRaWAN** через модуль **Ai-Thinker RA-08H** (ASR6601).

---

## 📌 Особенности архитектуры

* **Неблокирующий опрос кнопки (`button.py`):** аппаратные прерывания (`Pin.irq`) с защитой от дребезга контактов через `time.ticks_diff()`, не расходует процессорные циклы.
* **Надежный AT-парсер (`ra08h.py`):** построчный разбор ответов модема с таймаутами вместо проверки размера буфера или жестких индексов.
* **Cayenne LPP по стандарту (`cayenne.py`):** упаковка через `ustruct.pack` со знаковыми отрицательными температурами (16-bit two's complement) и компактными байтовыми буферами.
* **Отказоустойчивый опрос датчика (`humidity.py`):** ограниченное число попыток (retries) чтения DHT11/DHT22 без риска зависания устройства.
* **Энергосбережение экрана (`DisplayManager`):** автоматическое отключение OLED-дисплея по таймауту для экономии энергии и защиты от выгорания пикселей (пробуждение по нажатию кнопки).
* **Соблюдение регламентов LoRaWAN:** настраиваемый интервал отправки (Duty Cycle), поддержка Unconfirmed/Confirmed аплинков, возможность включения ADR.
* **Единая конфигурация (`config.py`):** все пины, параметры сети, тайминги и флаги вынесены в отдельный модуль.

## 🔌 Схема подключения (Pinout)

| Устройство / Функция | Пин ESP32 | Примечание |
| :--- | :--- | :--- |
| **RA-08H TX** | `GPIO 16` | Подключается к RX2 ESP32 |
| **RA-08H RX** | `GPIO 17` | Подключается к TX2 ESP32 |
| **OLED SSD1306 SCL** | `GPIO 26` | Аппаратный I2C0 (400 кГц) |
| **OLED SSD1306 SDA** | `GPIO 25` | Аппаратный I2C0 (400 кГц) |
| **Датчик DHT11 / DHT22**| `GPIO 18` | Цифровой вход (1-Wire DHT) |
| **Кнопка переключения DR**| `GPIO 22` | Нажатие замыкает на +3.3V (`PULL_DOWN`) |
| **Светодиод статуса** | `GPIO 14` | Индикация передачи / смены DR |

## 🚀 Быстрый старт

1. Настройте параметры сети и частоту отправки в [`config.py`](file:///home/nell/projects/RA-08H/config.py):
   ```python
   DEFAULT_DATARATE = 5    # DR5 (SF7 / 125 кГц)
   CONFIRMED_UPLINK = False # Unconfirmed (для снижения нагрузки на шлюз)
   TX_INTERVAL_SEC = 60    # Интервал между отправками
   ```
2. Загрузите файлы на плату ESP32 с установленным MicroPython (например, через `mpremote`, `ampy` или `Thonny`):
   ```bash
   mpremote cp config.py button.py cayenne.py humidity.py ra08h.py main.py :
   mpremote cp display/ssd1306.py :display/
   ```
3. Запустите устройство:
   * При старте устройство выполняет попытку OTAA Join (`AT+CJOIN=1,0,0,1`).
   * На экране отображается номер попытки и статус соединения.
   * После подключения начинается периодическая отправка телеметрии в формате Cayenne LPP.
   * Нажатие на кнопку на `GPIO 22` циклически меняет Data Rate (5 $\to$ 4 $\to$ 3 $\to$ 2 $\to$ 1 $\to$ 0 $\to$ 5) и при необходимости пробуждает дисплей.
